## Sobre
Planilha simples para projetar evolução patrimonial em FIIs, com dividendos mensais em cenários variados. Projeto executado como parte do Santander - Excel com Inteligência Artificial - 2º Semestre oferecido pela DIO.

## Como funciona
Com base em sua remuneração e perfil de investimento, é possível projetar diferentes cenários, variando valor mensal, taxa de juros e prazo, como um exercício de planejamento financeiro inicial.

## Funcionalidades
- Projeções financeiras
- Gráficos

## Estrutura das abas
- Base: tabela parâmetro para os perfis de investimento.
- Ferramenta: aba de interação e vizualização.

## Como usar
1. Abra a planilha no Excel.
2. Na aba Ferramenta, Preencha as células destacadas com fundo amarelo:
 E10 = Escolha seu perfil de investidor.
 E11 = Inserir a soma de rendimentos líquidos mensais.
 E13 = Valor que deseja investir mensalmente
 E14 = Prazo do investimento.
3. Vizualize as projeções através das tabelas e gráficos.
4. Altere quantas vezes for necessário para criar simulações diferentes.
